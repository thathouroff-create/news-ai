## ⚡ Ключевые возможности

### 1. 🧠 Редакционный интеллект (AI-Кураторство)
* **⚡ «3 главных факта» (TL;DR Bullet Points):** в окне быстрого чтения («📖 Сводка») читатель за 15 секунд получает кристальную выжимку сути:
  1. *Что произошло?* (Прямой факт без информационного шума).
  2. *Детали и цифры* (Суммы, проценты, финансовые показатели, даты и действующие лица).
  3. *Контекст и последствия* (Причины, развитие событий и значение для общества).
* **🛡️ Анти-кликбейт фильтр (De-Clickbait AI):** алгоритм автоматически распознаёт манипулятивные шаблоны (*«Шок!»*, *«Срочно!»*, *«Вы не поверите»*, клиффхэнгеры с многоточиями, агрессивный капслок) и нейтрализует их в спокойный объективный заголовок с бейджем `✨ Без кликбейта`. Оригинальный заголовок доступен при ховере/клике.
* **⏱️ Хроника развития сюжета (Story Timeline):** для резонансных инфоповодов, освещаемых несколькими изданиями, строится интерактивная вертикальная шкала времени с указанием этапов, первоисточников и временных меток.

### 2. 🔥 Умное ранжирование (Hot Score 2.0)
* **Сюжетный мультипликатор (Кластеризация):** если о новости сообщили сразу несколько независимых СМИ, инфоповод получает буст от **`2.5x` до `5.5x`** (`clusterCount^1.3`).
* **Тематический резонанс:** высокий приоритет темам, напрямую влияющим на жизнь читателя (курс рубля/валют, ставки ЦБ, налоги, инфляция, цены, указы и законы, прорывы в ИИ).
* **Анти-монополия источников:** алгоритм следит, чтобы в ленте не шли подряд более 2 материалов от одного СМИ.
* **Переключатель режимов:**
  - **🔥 Главное:** алгоритмический рейтинг резонанса и важности с выделением главной темы дня (`top-card`).
  - **⏱ Свежее:** строгий хронометраж последних событий минута в минуту.
  - **⭐ Закладки:** локальное изолированное хранилище избранных статей.

### 3. 📖 Мгновенное чтение (Instant Reader Modal)
* **Чистый текст без рекламы:** чтение статьи прямо внутри приложения в красивой модалке без всплывающих баннеров и пейволлов.
* **Автоматический перевод мировых изданий:** иностранные новости (*The Verge, TechCrunch, Phys.org, ScienceDaily, PC Gamer, Eurogamer, BBC*) автоматически переводятся на русский язык.
* **Сверка с первоисточником:** переключатель `[EN Оригинал / RU Перевод]` внутри модалки сводки.
* **Доступность без VPN:** сохранённая сводка читается беспрепятственно, даже если сайт первоисточника блокируется в РФ.

### 4. 🎨 Адаптивный кроссплатформенный дизайн
* **Desktop Bento Grid (768px – 1920px+):** продуманная двухколоночная сетка с полноширинной главной карточкой, объединённым поиском по клавише `/` и горячей клавишей обновления `R`.
* **Mobile-First (320px – 430px):** жест **Pull-to-Refresh**, симметричные неразрывные кнопки карточек, память скролла по вкладкам (старт с `0px` на новых вкладках).
* **3 высококонтрастные темы:** Тёмная (OLED), Светлая (WCAG AA Daylight), Индиго (Cyberpunk).
* **Динамическое масштабирование шрифта:** от `85%` до `135%` с сохранением пропорций и сетки.

### 5. 📈 Финансовый терминал и виджет погоды
* **Курсы валют ЦБ РФ:** USD, EUR, CNY с расчетом дневных изменений и номинала.
* **HiDPI Sparkline график на Canvas:** интерактивная 7-дневная динамика котировок при клике на валюту.
* **Погода в реальном времени:** виджет в шапке и подробное окно с данными Open-Meteo (температура, влажность, давление, ветер, геопозиция).

### 6. 🔒 Безопасность и офлайн (AppSec & PWA)
* **Строгий Content-Security-Policy (CSP):** `script-src 'self'`, нулевой `eval()`, нулевой inline `onclick`/`onerror`.
* **5-символьное экранирование:** защита от XSS в `escHtml()` (`&`, `<`, `>`, `"`, `'`) и строгая валидация протоколов `safeUrl()` (`https:`, `http:`).
* **PWA Service Worker v4.3:** Network-First кэширование, офлайн-доступ к сохранённым новостям и автоматическое обновление при выходе свежей версии.

## 📂 Структура репозитория

```text
news-ai/
├── index.html                   # Семантическая разметка (Desktop Bento + Mobile Shell)
├── styles.css                   # Адаптивная дизайн-система (WCAG AA, темы, анимации)
├── app.js                       # Ядро: Hot Score 2.0, De-Clickbait, TL;DR, Sparkline, PWA
├── sw.js                        # Service Worker (авто-кэширование, офлайн-режим)
├── manifest.json                # Манифест PWA (иконки, шорткаты #hot, #latest, #bookmarks)
├── fetch-feeds.js               # Серверный RSS-сборщик (Node.js, RFC-2822 парсер, кластеризация)
├── CHANGELOG.md                 # Детальная история версий и релизов
├── data/
│   └── latest.json              # Актуальный серверный снапшот новостей и курсов валют
├── icons/                       # Векторные и растровые иконки PWA (SVG, 192px, 512px)
└── .github/
    └── workflows/
        ├── deploy.yml           # CI/CD деплой статики на GitHub Pages
        └── update-feeds.yml     # Cron-запуск обновления ленты каждые 2 часа
```

## 🚀 Локальный запуск

Репозиторий не требует сложных сборок (zero-build architecture) и запускается любым статическим веб-сервером:

### Вариант 1. Через Python
```bash
python -m http.server 8080
# Откройте в браузере: http://localhost:8080
```

### Вариант 2. Через Node.js / npx
```bash
npx serve .
```

### Вариант 3. Обновление серверного снапшота вручную
```bash
node fetch-feeds.js
```
